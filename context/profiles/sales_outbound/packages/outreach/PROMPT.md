# Sales outbound

Sales messages follow the base writing rule, the correspondence rule and their references in full; this rule adds the sales layer and holds the top authority on sales outbound. The recipient owes the sender nothing, so the message opens with why the topic concerns them, earns each next sentence with something verifiable, offers one step and leaves an easy out. A consuming repository keeps only its mechanics below this profile; a genuine conflict with the correspondence profile or with a consumer's compliance rule goes to whoever owns the writing rules.
