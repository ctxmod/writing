# American Vocabulary

High-frequency American variants, with the false friends that trip
British-trained writers. The pattern-level sets live in the spelling
rule; this table covers whole-word choices.

## Everyday variants

| British | American |
| --- | --- |
| flat | apartment |
| autumn | fall (also "autumn", more formal) |
| holiday | vacation |
| pavement | sidewalk |
| lorry | truck |
| lift | elevator |
| queue | line |
| nappy | diaper |
| petrol | gas / gasoline |
| wardrobe | closet |

## Institutions and paperwork

| British | American |
| --- | --- |
| cheque | check |
| bill (restaurant) | check |
| solicitor / barrister | lawyer (attorney in legal paperwork) |
| post | mail |
| postcode | ZIP code |
| ground floor | first floor |
| first floor | second floor |

The floor offset is the classic silent error: a British "first
floor" is an American "second floor", and meeting instructions drift
by one storey.

## False friends

- "Quite" qualifies in British use ("quite good" = somewhat good) but
  strengthens in American use ("quite good" = very good).
- "Table a motion" means to postpone it in American procedure, to
  propose it in British.
- "First floor" starts one storey up compared with British use.
- "Fortnight" reads as affected or unclear in American prose; say
  "two weeks".
- "Trainer" names the fitness professional in American use; the
  footwear word is "sneaker".

Hold the vocabulary choices with the same consistency as the
spellings: one variety per document, chosen before the first
sentence.
