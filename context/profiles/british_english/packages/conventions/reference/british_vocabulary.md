# British Vocabulary

High-frequency British variants, with the false friends that trip
American-trained writers. The pattern-level sets live in the spelling
rule; this table covers whole-word choices.

## Everyday variants

| American | British |
| --- | --- |
| apartment | flat |
| fall (season) | autumn |
| vacation | holiday |
| sidewalk | pavement |
| truck | lorry |
| elevator | lift |
| line (queue) | queue |
| diaper | nappy |
| gasoline | petrol |
| closet | wardrobe |

## Institutions and paperwork

| American | British |
| --- | --- |
| check (bank) | cheque |
| check (restaurant) | bill |
| lawyer (UK context) | solicitor or barrister, by role |
| mail | post |
| zip code | postcode |
| first floor (US) | ground floor |
| second floor (US) | first floor |

The floor offset is the classic silent error: an American "second
floor" is a British "first floor", and meeting instructions drift by
one storey.

## False friends

- "Quite" strengthens in American use ("quite good" = very good) but
  qualifies in British use ("quite good" = somewhat good).
- "Table a motion" means to propose it in British procedure, to
  postpone it in American.
- "Pants" means underwear in British use; trousers are trousers.
- "Fortnight" is ordinary British frequency vocabulary (two weeks)
  and near-absent in American prose.
- "Bill" vs "check": a British restaurant brings the bill; asking
  for "the check" may work but marks the speaker.

Hold the vocabulary choices with the same consistency as the
spellings: one variety per document, chosen before the first
sentence.
