# Translation between Swedish and English

Translation follows the base writing rule and its references in full; this rule adds the genre layer. The target text is written from the original's facts in the target language's own structure, idiom and conventions, and a reader of the target text should not be able to tell it is a translation.

- idiom written from the facts, with the worked repairs from Swedish into English — [write_from_facts.md](rules/write_from_facts.md)
- the fact-base rule for both directions, conventions, one term per concept, original first, machine and agent drafts — <ctxmod_path path="ctx:github.com/ctxmod/writing/context::shared::principles@translation/reference/translation_principles.md" />
- svensk tillämpning: engelska ramar i svensk text, original först — `oversattning_och_terminologi` (module `writing_sv`, profile `webb`, package `genrer`)
- terminologi och parallellspråkighet, digest ur Parallella fackspråk och Snabba skrivregler — `terminologi_och_parallellsprak` (module `writing_sv`, profile `parallellsprak`, package `sprakbruk`)
