# Carry the Live Citations in the Example

Shared content teaches citation syntax inside code spans, where
citations are inert; the live forms stand only here, inside the
example package. Examples are never processed, so every citation
below is an inert shape — it demonstrates form without participating
in resolution, and nothing in shared committed content needs to
resolve for the module to validate.

## Worked citations

Every suffix names a declared locator of the source: `memo draft`,
`edit notes`.

Write so the reader can check you: state what the cited material
says, then cite it
[@writing_core_source_example_example, memo draft].

A locator stays inline at the site it qualifies and never travels
into the footnotes list
[@writing_core_source_example_example, edit notes].

Narrative placement names the source inside the sentence's grammar,
as when a draft was annotated by @writing_core_source_example_example
during the editing pass; suppress-author placement drops the name a
sentence already supplies, as in the revision
[-@writing_core_source_example_example] that reordered the memo's
opening.
