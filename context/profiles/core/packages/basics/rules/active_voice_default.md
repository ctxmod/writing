# Active Voice by Default

Default to the active voice: the actor acts. Go passive only when the actor is unknown, irrelevant to the point, or deliberately de-emphasized to keep attention on the object. The audit is to search the draft for a form of "be" followed by a past participle and, for each hit where none of the three reasons applies, name the actor and flip the clause.
