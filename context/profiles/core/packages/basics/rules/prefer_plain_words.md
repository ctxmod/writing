# Prefer Plain Words

Choose the common, concrete word over the rare or inflated one: "use", not "utilize"; "show", not "demonstrate"; "before", not "prior to". Use jargon only when the audience demonstrably shares the term and it is more precise than any plain substitute, and define it on first use in a document that may outlive that audience. Use precise technical terms where they do real work, and be as specific as a claim requires, naming the system, layer or practice it is about, so that the claim can be checked.
