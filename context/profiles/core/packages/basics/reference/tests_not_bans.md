# Tests, not bans

Every style rule in this module is written as a test. It states what the choice must achieve, how to check whether a given passage achieves it, and the narrow exception where the pattern is legitimate. A rule written this way lets a writer handle a case the rule did not foresee: the writer asks whether the passage achieves what the rule protects.

A bare prohibition is kept for three kinds of rule. Genuine errors (a wrong figure, a broken reference, a grammatical fault) have no legitimate use, so a test adds nothing. False claims are never acceptable, whatever their effect. Binding policy, such as a legal requirement or a standing decision by whoever owns the writing, applies whether or not a given case seems to need it.

When a rule seems to need an exception that the rule or the anti-pattern catalogue does not list, the case goes to whoever owns the rules. It is decided once and recorded with the rule or in the catalogue, so the next writer finds the ruling where the rule lives. House rulings that override this module's rules belong in the consumer's own layer (a house-style or personal module), not here.

The same principle applies to writing rules for agents: a test tells an agent what to achieve, where a ban only tells it what to avoid and leaves the unforeseen case open.

## Language

General principles are written in English. Examples stay in the language they illustrate, with their rewrites in the same language. Language-specific rules (for Swedish: Isof, Språkrådet, Swedish prose conventions) belong to the language module and are written in that language.
