# Scannable by Default

Correspondence is read once, fast, under interruption. Short
paragraphs, bullets for genuine enumerations, bold for the one thing
that must not be missed, and the next step stated at the end — that
is the default posture, and longer forms must justify themselves
against it.

## Rationale

The reader is triaging between your message and eleven others, on a
phone, before a meeting. Walls of prose get deferred, and deferred
messages decay into never. The mechanics are few: paragraphs of one
to three sentences; bullets only where the content is actually a
list (a bulleted flow of prose is padding wearing a costume); the
ask or the headline in the first screen, not after the signature
block; and a closing line that names the ball's next holder —
"I'll send the revised draft Friday; flag objections by Thursday" —
so the thread ends with a plan instead of an implication. Length
discipline follows: if a message needs five paragraphs, the fifth
is usually a second message, and sending it separately lets each
one be answered.
